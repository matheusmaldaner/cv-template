# Resume

The academic CV template I used for PhD applications in CS, HCI and ML. Pick whichever way you like to edit.

| | How |
|---|---|
| **Google Doc** | [Make a copy](https://docs.google.com/document/d/1h1jBoEAi1v6T8ZOFR_viD9F9XpnHBmyXGAzvsQ3Z_Ec/copy) (read the "how to use" tab first) |
| **Overleaf** | [Open in Overleaf](https://www.overleaf.com/docs?snip_uri=https://raw.githubusercontent.com/matheusmaldaner/cv-template/main/overleaf/resume.tex) (or upload [`overleaf/resume.tex`](overleaf/resume.tex)) |
| **AI agent** | Paste the prompt below into Claude Code, Codex, Cursor or any coding agent |

## AI agent

Open your agent in an empty folder and paste this:

```text
Build my academic CV from this template:
https://raw.githubusercontent.com/matheusmaldaner/cv-template/main/agent/resume.html

1. Download it into this folder as resume.html.
2. Ask me to paste my current resume or CV (text, PDF or LinkedIn export).
3. Fill the template with my information only. Never invent facts, numbers, dates or links.
4. List what is missing (dates, locations, mentors, venues, links) and ask me for it.
   For any section I have nothing for, ask whether to drop it.
5. Keep the template's style: one line per bullet, numbers over adjectives, newest first,
   my name in bold in author lists, papers tagged [J1], [C1], [P1].
6. Save resume.html and make resume.pdf (print it with headless Chrome if you can,
   otherwise tell me to open it in a browser and Save as PDF).
7. Show me the result and ask what to change.
```

## Tips

- Research first: interests, education, publications, then experience. Trim to 2 to 3 pages for PhD applications.
- One line per bullet, and lead with a number when you have one.
- Bold your name in every author list so readers find you fast.
